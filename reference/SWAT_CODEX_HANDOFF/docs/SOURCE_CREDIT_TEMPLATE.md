# Image source and credits workflow

The archive does **not** contain real photograph files. Download only from the source URLs in `REAL_IMAGE_MANIFEST.json`.

For each item record: original filename, photographer/creator, direct source link, date captured if supplied, Creative Commons license URL, attribution requirements, changes made, downloaded file checksum, crop and processing. Keep visible attribution in /sources and a nearby label where context matters. Do not use CC BY-SA derivatives without reviewing share-alike obligations. Do not pretend a Barikot panorama is an archaeological excavation photo. Do not claim the River map is geographic until coordinates are verified.

**Real-source imagery must be selected on composition**, not just licensing: judge readable text area, subject identity, camera angle, resolution, absence of watermarks, color compatibility, and mobile safe-crops. Reject photos that cannot support the section visually.

No generated people, no made-up heritage photos, no unrelated weaving images, no non-reusable stock. If a necessary craft or human portrait is unavailable, display a designed neutral editorial block and explicitly track `MISSING_PERMISSION_CLEARED_ASSET`.
